# الفحص البصري الآلي + الانحدار البصري (3A-326)

أداة شغل دائمة تنهي الصيد اليدوي لمشاكل الواجهة: سويب لقطات آلي لكل
شاشات التطبيق من إنتاج الديمو العام، وخط أساس معتمد، ومقارنة آلية عند
كل تغيير تُظهر الفروقات كتقرير صور — المراجعة البشرية تقرأ النتائج
بدل اللف في الشاشات.

## التشغيل

```bash
# سويب أدلة مؤرخ (لقطات كل الشاشات عند 390+360):
node e2e/visual/capture.mjs --out <dir>

# مقارنة انحدار: التقاط طازج + مقارنة بخط الأساس + تقرير
npm i --no-save pixelmatch@5.3.0 pngjs@7.0.0   # أدوات المقارنة (صندوق الأداة فقط)
node e2e/visual/compare.mjs [--out <report-dir>] [--fail-on-diff]
```

- `capture.mjs` يخرج بكود 1 إن فشلت أي شاشة (لا سويب ناقص يمرّ ككامل).
- `compare.mjs` يخرج 0 ما دامت الآلية سليمة (الفروقات بيانات في
  التقرير)، ويخرج 1 عند فشل الآلية نفسها (حارس العدّاد: لقطات
  صفر/ناقصة) — ومع `--fail-on-diff` يخرج 1 عند أي فرق فوق السماحية.
- تقارير المقارنة في `e2e/visual/reports/` (مُهمَلة في git عدا ما
  يُرفع كأداة CI)، وسويبات الأدلة المؤرخة في مساحة ملفات الهدف
  `~/workspace/goals/teacher-admin-app/files/visual-sweeps/<date>/`.

## قرار الأداة (موثّق بالأدلة — 2026-11-22)

**المعتمد: Puppeteer + pixelmatch على المكدّس القائم. المرفوض:
Playwright ‏toHaveScreenshot — لأسباب مقاسة لا تفضيلية:**

1. فحص جدوى فعلي لـ Playwright ‏(1.65.1) في هذه البيئة: التثبيت نجح
   (27 ثانية، ≈327MiB تنزيل/700MB قرص، صفر مكتبات نظام) ودورة
   لقطة→مقارنة→فرق عملت على صفحة محلية — **لكن Chromium الخاص به لم
   يعبر بروكسي الخروج الموثّق إطلاقاً** ضد أي URL حي
   ‏(`ERR_TUNNEL_CONNECTION_FAILED` في كل الإعدادات، بينما curl وNode
   يعبران البروكسي نفسه بنجاح). مكدّس Puppeteer القائم يتجاوز ذلك
   بنمط ريلاي Node fetch المثبت منذ 3A-311.
2. Playwright مكدّس متصفح ثانٍ كامل يضاعف ما يقدّمه Chromium القائم
   أصلاً في devDependencies؛ ‏pixelmatch يمنح نفس قدرة فرق البكسل +
   صور الفرق على المكدّس نفسه.
3. اتساق محلي/CI: الأداة نفسها تعمل هنا (حيث الدليل العامل اليوم)
   وفي CI بلا اختلاف سلوك.

إعادة النظر مشروطة بتغيّر أحد السببين 1–2 (خروج بلا بروكسي موثّق، أو
تقاعد مكدّس Puppeteer لسبب آخر).

## انضباط الحتمية

- **ساعة مجمّدة:** `Date` تُبدَّل عند `2026-11-21T22:00Z` ومنطقة
  المتصفح `Africa/Cairo` = الأحد 2026-11-22 00:00 EET في أي بيئة —
  فتواريخ «اليوم/الشهر الحالي/الأوقات النسبية» ثابتة بين التشغيلات.
- **حركة مسحوقة:** `prefers-reduced-motion` + CSS محقون يصفّر مدد
  الأنيميشن/الانتقالات؛ حالة دُفّي تثبت بعد الاستقرار.
- **استقرار قبل الالتقاط:** خمول شبكة + جاهزية خطوط + ثبات طول نص
  الصفحة + تمرير كامل (تحميل كسول) وإعادة للأعلى.
- **عزل المراحل:** العامة والديمو والبوابتان في سياقات متصفح منفصلة
  (زيارات العامة في سياق الجلسة عطّلت دخول الديمو في أول سويب —
  درس موثّق)، ودخول الديمو له إعادة محاولة واحدة بسياق جديد.
- **البوابتان:** رابط يُولّد من ملف طالب، يُزار في سياق مجهول،
  يُلتقط، ثم **يُبطَل** — وخط الأساس يُتحقق عددياً بعده (صفر توكنات
  نشطة) عبر `npm run test:authz`.
- شاشات بسماحيات فرق أعلى (1% بدل 0.2%) موسومة `volatile` في
  `screens.mjs` بسبب طوابع خادم حقيقية — تُراجع عند كل إعادة أساس.

## خط الأساس

- المكان: `e2e/visual/baseline/{390,360}/*.png` + `baseline.json`
  (تاريخ البناء، بصمة حزمة إنتاج، الساعة المجمّدة، العدّادات).
- بُني على إنتاج ما بعد 3A-325 (انظر baseline.json) واعتُمد بعد
  المراجعة الشاملة الأولى (بند المشاكل المجمع يوثّق ما فيه).
- **إعادة البناء** (بعد تغيير واجهة مقصود): شغّل capture إلى مجلد
  الأساس، راجع اللقطات، حدّث baseline.json، واذكر السبب في الكوميت —
  الأساس لا يُحدَّث صامتاً أبداً.

## CI

وظيفة `visual-regression` في `.github/workflows/ci.yml`:
‏continue-on-error (معلوماتية — نمط تبنّي الأدوات، المعايير الحية
v1.3)، ترفع تقرير الفروقات كأداة قابلة للفتح. الترقية لوظيفة حاجبة
= تمرير `--fail-on-diff` + إسقاط continue-on-error بقرار لاحق بعد
أسابيع إشارات مستقرة. ملحوظة تشغيلية: حساب GitHub Actions متوقف
بفوترة الحساب (موثّق منذ نونو ق19) — الوظيفة مثبّتة وموثّقة،
والتشغيل المحلي هو الدليل العامل حتى تعود Actions.

## أعراض التقاط معروفة (ليست عيوب تطبيق)

- في اللقطات كاملة الصفحة يظهر شريط التنقّل السفلي الثابت عند حدّ
  أول ارتفاع شاشة تقريباً (سلوك عناصر fixed مع التصوير الممتد) —
  موضعه ثابت ما ثبت محتوى الصفحة، فلا يصنع ضجيج انحدار.
- سبلاش الإقلاع المتحرك (3A-325) لا يظهر في اللقطات: الالتقاط بعد
  الاستقرار الكامل عمداً.
