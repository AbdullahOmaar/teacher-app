## §1 — فجوة 40: اختبارات عقود API ✅

**الأداة المختارة ولماذا:** الخطة سمّت Bruno/Pact/Schemathesis كمرشحين. التقييم العملي:

- **Pact**: عقود consumer/provider تحتاج وسيطًا (broker) أو ملفات pact متبادلة بين ريبوين — سطحنا ريبـو واحد بدوال حدّية بأنوية نقية قابلة للحقن، فالبنية زائدة بلا مقابل.
- **Schemathesis**: يحتاج مخطط OpenAPI + خادمًا حيًّا — لا مخطط OpenAPI في المشروع، وبناء واحد لمجرد الفحص قفزة نطاق.
- **Bruno**: مجموعات يدوية بواجهة رسومية — لا تعمل كفحص CI حاجب من نفسها.

**المبني بدلًا من ذلك (صفر اعتماديات جديدة، وفق سياسة الاعتماديات):** `scripts/contract_tests.mjs` يشغّل نفس `core.ts` الإنتاجي للدوال الخمس باعتماديات وهمية بنفس عقود الحقن، ويثبّت **العقد العام** تحديدًا (وهو ما لا تغطيه المحاكيات السلوكية القائمة `simulate-*.mjs`):

- كل رد خطأ: مغلف واحد `{error:{http_code: <نفس الحالة>, message: <نص>}}` + `Content-Type: application/json`.
- أكواد الحالة الموثقة لكل بوابة: kill switch ‏503، غياب JWT ‏401، توقيع فاسد 401، ملكية 403، إعداد ناقص 422، حمولة فاسدة 400، طريقة خاطئة 405.
- أشكال النجاح حرفيًّا: رسالة واتساب `{ok, log_id, message_id}`، إرسال تجريبي `{ok:true}`، OTP وهمي `{}`، تحقق Webhook ‏= نص الـchallenge حرفيًّا بـ`text/plain`، أحداث حالات `{ok, updated}`، إجابة مساعد `{status:'answered', run_id, tool, result}`.

**النتيجة: 120/120** — مربوطة خطوة حاجبة في وظيفة `check-and-test` (`npm run test:contracts`).

## §4 — فجوة 44: حقن الأعطال والمرونة ✅

`scripts/fault_injection.mjs` (**23/23**) على الأنوية الإنتاجية، في بيئة اختبار فقط:

- **مزوّد Meta يسقط شبكيًّا / يرفض HTTP 500 / تنقطع مهلته (AbortError)**: ردّ 502 بالمغلف الموحد + سجل الرسالة يُختم `failed` بسبب واضح (network error / كود المزوّد) — لا نجاح مزيّف.
- **فشل كتابة سجل الرسالة أولًا**: 500 والإرسال **لا يحدث أصلًا** (لا إرسال بلا أثر قابل للمتابعة — تحقق بعدّاد نداءات المزوّد = 0).
- **فشل إرسال تجريبي**: ختم حدّ المعدل `markTested` لا يُكتب إلا بعد نجاح فعلي (الفشل لا يعاقب المدرس بنافذة انتظار).
- **المساعد**: فشل قيد التدقيق → الإجابة تُحجب كليًّا (500)؛ فشل جلب البيانات → خطأ صريح يُرمى، لا إجابة فارغة مزيّفة.
- **Webhook**: أحداث لمعرّفات رسائل غير معروفة → 200 ‏`{ok:true, updated:0}` (لا إسقاط للمعالج).
- **جانب العميل**: 5 اختبارات وحدة جديدة (`src/lib/supabaseErrors.test.ts`) تثبّت أن الخطأ الخام لا يصل للمستخدم (23503 → رسالة عربية / `fkMessage`، والقيم الشاذة → احتياطي موثق).

ملحوظات صادقة: الأنوية لا تفرض مهلة نداء خاصة على `fetch` (تعتمد مهلات المنصة Deno/المتصفح — سيناريو المهلة حُوكي برفض AbortError وهو نفس مسار الكود)؛ وطابور الحضور الأوفلاين مغطّى أصلًا باختبارات قائمة (`offlineQueue.test.ts`). مربوطة خطوة حاجبة في CI (`npm run test:faults`).
