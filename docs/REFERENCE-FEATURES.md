## الحالات المعتمدة (بالحرف — ست حالات)

مخططة · قيد البناء · في الكود فقط · حية · مطفأة بقرار · محذوفة

| الحالة | معناها بالضبط (قاعدة قابلة للتدقيق) |
|---|---|
| **مخططة** | لا كود بعد — فكرة/بند مسجل ينتظر البناء (قسم «مخططة» أسفل هذا السجل) |
| **قيد البناء** | لسه بتتبني: في PR مفتوح أو مهمة جارية، ولسه ما اندمجتش في `main` |
| **في الكود فقط** | مبنية ومدموجة في `main` لكنها مش حية: مهاجرة غير مطبّقة (0051–0061) أو بناء غير منشور — مجمدة عند بوابة (تجميد فيز/قرار). تسميتها «حية» أو «قيد البناء» خطأ في الحالتين |
| **حية** | كود العميل داخل بناء الإنتاج (سلف دمج PR #14 ‏`36391a49`) **و** مهاجراتها مطبّقة (≤0050) **و** علم/شرط تشغيلها شغال **و** مستخدم حقيقي يقدر يوصلها |
| **مطفأة بقرار** | موجودة لكنها مطفأة/غير مُطلقة بقرار مسمى (صاحبه وتاريخه في عمود شرط التشغيل/الملاحظات)؛ وسطحها إن ظهر يعرض حالة مصممة «قريبًا» أو رسالة مهذبة — خاصية العرض دي تُسجَّل مع الحالة الحقيقية، لا بديل عنها (قاعدة «لا أخطاء خام» 2026-11-26 — الجرد الكامل في `docs/DORMANT-FEATURES-INVENTORY.md`) |
| **محذوفة** | أُزيلت من المنتج ويبقى صفها في السجل للتاريخ فقط (لا صفوف حالياً) |

وسوم رحلات [مرجع الأعمال](REFERENCE-BUSINESS.md) بتطابق الحالات:
**[حي]=حية، [كود]=في الكود فقط، [نايم]=مطفأة بقرار**.

قواعد السجل: فيتشر مش في السجل = مش موجودة. أي فيتشر غير حية
وواجهتها باينة للمستخدم: حالة «قريبًا» مصممة أو رسالة مهذبة —
ممنوع خطأ خام.

«شرط التشغيل» = ما ينقص الفيتشر لتعمل حياً كما هو مقصود.
