# الدخول بجوجل (3A-931) — وثيقة الإعداد والتشغيل

الكود مكتمل في التطبيق: زر «الدخول بجوجل» في شاشة الدخول (وضعا
الدخول والتسجيل) يستدعي `signInWithOAuth({ provider: 'google' })`
والرجوع يهبط على `/login` حيث يلتقط `AuthProvider` الجلسة،
ومستخدم جوجل الجديد يمرّ بنفس إكمال الحساب (Onboarding) —
**لا خطوة كود بعد هذه الوثيقة**؛ التفعيل إعداد فقط، ومتى لم
يُفعَّل المزود بعد يرى المستخدم رسالة عربية مصممة («الدخول
بجوجل مش مفعّل على المنصة لسه») لا خطأ خاماً.

## ١) مشروع Google Cloud

1. أنشئ مشروعاً في Google Cloud Console (أو استخدم مشروعاً قائماً
   مخصصاً للتطبيق).
2. شاشة موافقة OAuth (APIs & Services ← OAuth consent screen):
   النوع External، اسم التطبيق الظاهر للمستخدم + بريد دعم —
   الاسم الظاهر قرار براند محفوظ للمالك.
3. بيانات الاعتماد (Credentials ← Create Credentials ← OAuth
   client ID): النوع **Web application**.
4. **Authorized redirect URI** واحد إلزامي:
   `https://<PROJECT_REF>.supabase.co/auth/v1/callback`
   (نفس رابط رد Supabase لكل البيئات — البيئة تُميَّز من إعداد
   المزود في مشروع Supabase نفسه لا من الرابط).
5. انسخ **Client ID** و**Client Secret** — يُدخلان في الخطوة ٢
   فقط، لا يُحفظان في الكود أو المستودع أبداً.

## ٢) تفعيل المزود في Supabase

لكل مشروع Supabase (الحالي «ديمو» للإثبات الحي، و«برودكشن» عند
إعداده غداً ببيانات اعتماد منفصلة تحت حساب التطبيق المخصص):

1. Authentication ← Providers ← Google: فعّل، والصق Client ID
   وClient Secret من الخطوة ١.
2. Authentication ← URL Configuration: تأكد أن أصل التطبيق
   (`https://teacher-app-prod.vercel.app` للحالي) ضمن
   **Redirect URLs** المسموحة — مسار الرجوع الكامل الذي يطلبه
   التطبيق هو `<الأصل>/login`، وGoTrue يطابق الأصل/المسار
   بقائمة السماح هذه بعد رد المزود على رابط الـcallback أعلاه.

## ٣) التحقق الحي بعد التفعيل

1. افتح شاشة الدخول ← «الدخول بجوجل» ← اختر حساباً.
2. المتوقع: رجوع للتطبيق بجلسة قائمة — حساب قائم يدخل مباشرة،
   وحساب جديد يهبط على «كمّل إعداد حسابك» بنفس شاشة Onboarding
   واسمه معبّأ من حساب جوجل.
3. إلغاء الاختيار عند جوجل يرجع برسالة «اتلغى الدخول بجوجل»
   المصممة في شاشة الدخول، بلا أي نص إنجليزي خام.

## ٤) ملحوظات

- حساب جوجل ببريد مسجّل أصلاً بالبريد/كلمة المرور: GoTrue يربط
  الهوية بنفس المستخدم عند تطابق البريد المؤكد — لا حساب مكرر.
- إيقاف الميزة = تعطيل المزود من لوحة Supabase فقط؛ الزر يبقى
  ويرجع بالرسالة المصممة «مش مفعّل لسه»، لا نشر كود لازماً.
