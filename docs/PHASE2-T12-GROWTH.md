## 8) حادثة موثقة بصدق — تلوّث تجهيزات authz (خطأي، لا عطل منتج)

أول تشغيلتي `npm run check` تداخلتا: ظننت الأولى فشلت (بلاغ إكمال
مبكر مضلّل) فأطلقت الثانية بينما authz الأولى حي، فاصطدمت
التجهيزات، ثم «نظّفت» تجهيزات بينما جولة ثالثة حية — كل فشل
authz في هذه المهمة (125/127 مرة، وانقطاع سجل مرتين) سببه هذا

127/127 ثلاث مرات (منها الفحص الرسمي قبل كوميت بند 4). التنظيف
الجراحي حذف تجهيزات authz-* فقط (3 مستخدمين + صفّي مدرس + عضو)
وأعاد صف enrolment_links للديمو حرفياً بعد لقطات السنتر، وتُحقق
الأساس 18/18 بعد كل خطوة. درس مسجل: لا تنظيف ولا تشغيل ثانٍ قبل
التحقق من موت العملية الأولى فعلياً (ps لا بلاغات الإكمال).
