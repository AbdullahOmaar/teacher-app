# فهرس حزمة مرجع مستر (Reference Package Index)

> **قاعدة حية:** حزمة المرجع دي بتتحدث مع كل فيتشر وكل نشر —
> مفيش فيتشر تتقفل من غير تحديث السجل والمرجع (أمر مالك
> 2026-11-26، بند 3A-907). **آخر تحديث:** 2026-11-26.
>
> نسخة مستر هي أول تطبيق حي لـ«قالب مرجع التطبيق» الموحد في
> الشركة. **قواعد التحديث الكاملة (مين يحدّث وامتى) تعيش على
> مستوى القالب بس** في
> `~/workspace/ops-system/app-reference-template/UPDATE-RULES.md`
> — ملف القالب ده مش جزء من نسخة التطبيق؛ النسخة = الخمسة
> مستندات دي + الفهرس ده.

## اتفاقيات النسخة

- ترويسة «قاعدة حية» + سطر «آخر تحديث» + ترابط بين الخمسة في
  صدر كل مستند.
- حالات الفيتشرز بالمفردات الست المعتمدة حرفياً: مخططة · قيد
  البناء · في الكود فقط · حية · مطفأة بقرار · محذوفة — ووسوم
  رحلات مرجع الأعمال بتطابقها: [حي]=حية، [كود]=في الكود فقط،
  [نايم]=مطفأة بقرار.
- أي تعديل هيكلي على الحزمة بيترجع لمالك القالب (خط اوس —
  المسؤول) ولنسخة مستر معاً قبل ما يثبت (اتفاق 2026-11-26).
