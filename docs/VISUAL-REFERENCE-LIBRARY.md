# مكتبة المراجع البصرية ونمط تقسيم الكروت — وثيقة حية

> **الموطن:** المهمة 16 (3A-720)، بند 6 (ج5/ج3). وثيقة حية تُحدَّث مع
> كل دفعة واجهة: قاعدة المالك — «ابحث عن المراجع البصرية قبل شغل
> الكروت والأزرار» + بوابة الجودة: لا واجهة تُشحن بلا فحص شاشة موثق
> عند 375px. آخر تحديث: 2026-11-26 (T16).

## 1) نمط تقسيم الكروت المعتمد (من دفعة 3A-697 — مُثبت على الإنتاج)

تشريح موحّد لكل كرت معلومات في التطبيق:

1. **سطر العنوان أولاً:** الاسم/العنوان + شارة الحالة في أقصى طرف
   السطر نفسه (لا سطر مستقل للشارة).
2. **سطر الأرقام:** القيم الأساسية بنفس التسلسل البصري في كل الكروت
   (قيمة ← وحدة/سياق).
3. **سطر الأفعال الأخير:** الأزرار **في صف أفقي واحد** — ممنوع
   التكديس العمودي بعرض كامل (قاعدة مالك 2026-11-25). زر التوسيع
   («عرض الفواتير/الأسماء») يجلس **داخل سطر النص الأخير بجانبه** لا
   على سطر مستقل (تعديل مالك 2026-11-24).
4. **أزرار صغيرة أيقونة-أولاً** (icon-first) بارتفاع موحّد داخل الكرت
   الواحد وعبر الشاشة، وحركة واحدة ناعمة عند الظهور — المحتوى يظهر
   دفعة واحدة لا متقطعاً.
5. **لا شيفرونات زخرفية** في قوائم الكروت (أُزيلت من قائمة الفواتير
   في 3A-697) — التفاعل يُفهم من الكرت نفسه.

مرجع التنفيذ: مكونات دفعة 3A-697 (كروت الإشعارات الموحدة، كروت
المتأخرات، كرت نتائج الامتحانات المعاد تشكيله، أزرار كروت المجموعات
في صف واحد بارتفاع واحد) + حقول تاريخ الامتحان كرقائق عربية موحدة
(chips) بدل منتقي النظام (هاتف المالك بلا showPicker — الدرس: الحقل
الأصلي يبقى هدف لمس شفافاً فوق الرقاقة).

## 3) أتمتة السويب (حالة فجوة 42 بعد إصلاح T16)

- الأداة: `e2e/visual/capture.mjs` (Puppeteer + relay) و`compare.mjs`
  للمقارنة بخط الأساس؛ وظيفة CI ‏`visual-regression` معلوماتية
  (continue-on-error) حتى تستقر الإشارات أسابيع — الترقية لبوابة
  حاجبة (`--fail-on-diff`) قرار لاحق بالأدلة كما هو موثق في ci.yml.
- إصلاحا T16 (سباقا الالتقاط): (أ) مرحلة دخول الديمو تشمل شاشات
  البوابات — تشغيل `--only portal-*` لم يعد يتخطى الدخول؛ (ب) كل
  النقرات داخل الصفحة بـevaluate ذرّي طازج بلا مقابض عناصر
  (clickByText + زر توليد رابط البوابة) + ‏protocolTimeout ‏600s.
  الإثبات: `--only portal-parent,portal-student` عند 390 = ‏2/2
  (كان يفشل بمهلة/مقبض فاسد).
- تشغيل السويب الكامل قبل أي دفعة واجهة مجمّعة، وعند 390+360 معاً،
  والساعة مجمّدة (2026-11-21T22:00Z) لثبات المقارنة.
