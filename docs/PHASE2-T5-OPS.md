## §5 — تسجيل MCP عبر stdin (ج14-4) — منفَّذ ومختبَر

### 5-1 الإجراء

  من stdin — **التوكنات لا تظهر في سطر الأوامر أبدًا** (`ps`، سجل الصدفة، سجلات العمليات).

### 5-2 الاختبارات الحية (2026-11-24 ~22:50 EET، بثنائي `claude` مزيف يسجّل argv وstdin)

## §6 — إعادة اختبار الخطافات + معمارية بدائل الإنفاذ + كتالوج الانتهاك المزروع

### 6-1 التساهلات الثلاثة الموثقة (سجل تغييرات Claude Code 2.1.327–2.1.331، أُعيدت قراءته 2026-11-24)
1. **PreToolUse في Code Mode يفشل مفتوحًا:** خطاف يخطئ لم يعد يرفض استدعاء أداة السكربت،
   ما لم يحمل `"onFailure": "block"` — الحارس المتعطل يصبح مرورًا صامتًا.
2. **PostToolUse المُدارة تفوّت المرفوض قبل التشغيل:** الاستدعاءات المرفوضة قبل أن تعمل لا تترك
   سجلًا هناك؛ `PostToolBatch` يرى معظمها لكن بلا وسم «مرفوض».
3. **UserPromptSubmit لا يعمل على مخرجات سكربتات Code Mode** (حتى المُدارة) — التنقيح الذي اعتمد
   عليها توقف؛ البديل: خطاف PostToolUse مع `updatedToolOutput`.
- ملحقات: `"onFailure": "block"` أُضيف لخطافات `mcp_tool` أيضًا؛ إعادة كتابة أمر عبر خطاف
  PermissionRequest إلى أمر مستثنٍ من Sandbox تجعله يعمل **خارج** Sandbox؛ الأسواق المُدارة تُحدَّث
  تلقائيًا افتراضيًا في إصدار في/بعد 30 نوفمبر ما لم يُضبط `"autoUpdate": false`.

### 6-2 معمارية بدائل الإنفاذ — القاعدة الملزمة
**لا إنفاذ بخطاف واحد.** كل قاعدة حارس تحتاج طبقتين مختلفتي الفشل:
- طبقة آلية (lint/فحص/CI) + طبقة تحقق (أداة `linear_verify.py` / مراجعة PR / اختبار حي).
- كل خطاف حارس **يجب** أن يحمل `"onFailure": "block"` حيث يجب أن يرفض عند الخطأ.
- تنقيح المخرجات يعيش في PostToolUse مع `updatedToolOutput`، لا في UserPromptSubmit.
- سجلات التدقيق لا تُبنى على PostToolUse المُدارة وحدها (تفوّت المرفوض) — تُبنى على PostToolBatch + سجل CI.

و`tsc strict` لا يمنع `any` الصريح. إنفاذهما اليوم **مراجعة بشرية فقط** — وهذا بالضبط ما تعنيه
«لا إنفاذ بخطاف واحد»: طبقة واحدة (المراجعة) تفشل بصمت عند التعب.
- **الإجراء:** تُقيَّم إضافة قاعدتي oxlint (`typescript/no-explicit-any` و`no-console` مع قائمة
  سماح للسجلات المقصودة) كـPR لاحق؛ حتى ذلك الحين تبقى القاعدتان **مراجعة-إلزامية** في قائمة مراجعة PR،
  ويُعاد تشغيل هذا الكتالوج عند كل تغيير إنفاذ.
- **ملاحظة منهجية:** سلسلة اختبار أولية بتوكنات متسلسلة الحروف لم تُكتشف لأن إنتروبياها دون عتبة القاعدة —
