# خط الأنابيب البصري FLUX.2 Pro (مهمة 12 — بند 3أ)

> مصدر البند: مقترح R&D براند. **وثيقة تصميم خط أنابيب فقط** — أي
> استخدام فعلي لأداة توليد مدفوعة قرار مالك (أدوات سجل الذكاء:
> الإضافة مسموحة فقط لما يُستخدَم فعلاً، والخطط المدفوعة قرار مالك).
> تاريخ الإعداد: 2026-11-26.

## 1) لماذا خط أنابيب لا «صور متفرقة»؟

الهوية البصرية للشركة (أوتو OTO وجه الشركة، ودُفّي داخل مستر فقط —
قواعد بنك المحتوى 2026-11-24) تحتاج صوراً متسقة الأسلوب عبر
المشاريع الخمسة. التوليد العشوائي صورةً صورةً ينتج أسلوباً مختلفاً
كل مرة. الخط هنا يحوّل التوليد إلى عملية قابلة للتكرار والمراجعة:
مدخلات ثابتة → برومبتات مقولبة → مراجعة بشرية → أرشيف منظم.

## 2) المدخلات (Inputs)

| مدخل | مصدره | ملاحظة |
|------|--------|--------|
| دليل الأسلوب | بنك المحتوى الاجتماعي (الخطة 2026-11-24) + هوية كل مشروع | ألوان/مزاج/ممنوعات لكل مشروع |
| شخصية أوتو | ملفات الماسكوت المعتمدة | المرجع البصري الوحيد لوجه الشركة |
| قائمة اللقطات | خطة المحتوى (CONTENT-CHANNELS-PLAN) + خطة الموسمية | كل لقطة مرتبطة بحلقة/مناسبة |
| نصوص الظهور | عناوين الحلقات المعتمدة | النص العربي داخل الصورة يُراجَع حرفياً (نقطة فشل معروفة في التوليد) |

## 3) الخطوات (Pipeline)

1. **طلب لقطة** — بطاقة طلب: المشروع، الاستخدام (غلاف Reel/منشور/
   صفحة)، الأبعاد (9:16 أو 1:1 أو 16:9)، الموعد المطلوب (من خطة
   الموسمية).
2. **صياغة البرومبت من قالب** — قالب ثابت لكل نوع لقطة: [الأسلوب
   العام] + [موضوع اللقطة] + [قيود: بلا وجوه حقيقية، بلا نصوص
   مولّدة داخل الصورة إلا المقصودة، ألوان الهوية].
3. **التوليد (FLUX.2 Pro)** — 4 مرشحات لكل لقطة على الأقل.
4. **مراجعة بشرية (بوابة)** — اختيار مرشح واحد أو رفض الكل وإعادة
   الصياغة؛ معايير الرفض: نص عربي مشوّه، يد/وجه مشوّه، خروج عن
   الهوية، شبه بشخص حقيقي.
5. **معالجة لاحقة** — قصّ/أبعاد نهائية + إضافة النصوص العربية
   ببرنامج تحرير (لا نصوص مولّدة داخل النموذج للعربية الحساسة).
6. **أرشفة** — ملف باسم موحّد (مشروع-تاريخ-لقطة) + سجل: البرومبت،
   المرشح المختار، المراجع، الاستخدام الفعلي.

## 4) المخرجات (Outputs)

- صورة نهائية جاهزة للنشر بأبعاد قناتها + نسخة أرشيفية كاملة الدقة.
- سطر سجل لكل لقطة (يُستخدم في تقارير سجل أدوات الذكاء: الأداة +
  ما أنتجته).
- مكتبة برومبتات مقولبة تنمو مع كل لقطة ناجحة (الأصل الحقيقي للخط).

## 5) نقاط القرار (Decision points)

| النقطة | صاحبها | الحالة |
|--------|---------|--------|
| اعتماد FLUX.2 Pro أداةً مدفوعة + سقف إنفاق | المالك | ⛔ لم يُقرَّر — لا استخدام قبل القرار |
| اعتماد دليل أسلوب كل مشروع | المدير (من بنك المحتوى) | البنك موجود؛ الاعتماد عند أول استخدام |
| قبول/رفض كل لقطة | مراجعة بشرية (QA بصري) | بوابة دائمة — لا نشر آلي |
| ظهور منتج حقيقي في صورة | المالك | قواعد البنك: المنتجات مموّهة في التشويق |

## 6) التكلفة والمخاطر (صادقة)

- التوليد مدفوع بالصورة/الاشتراك — لا رقم هنا لأن التسعير يتغير
  ويُعرض على المالك لحظة القرار من مصدره الرسمي.
- المخاطر: نص عربي مشوّه (تُعالج بالمعالجة اللاحقة)، اتساق الشخصية
  عبر اللقطات (يُعالج بالمرجع البصري الثابت)، حقوق الاستخدام
  التجاري (تُقرأ شروط الخطة المدفوعة قبل الاعتماد — خطوة القرار).
- البديل المجاني القائم: تصوير حقيقي + قوالب تصميم (Canva من سجل
  الأدوات المعتمد) — الخط لا يلغي البديل؛ يضيف طبقة توليد عند الحاجة.

## 7) أول تشغيل تجريبي مقترح (بعد قرار المالك فقط)

5 لقطات: غلافا حلقتي R1-1 وR2-1 (من خطة المحتوى) + صورة موسمية
لرمضان (من خطة الموسمية) + صورتا هوية عامة للشركة. نجاح التجربة =
5/5 مقبولة من أول أو ثاني جولة توليد، وتُسجَّل الأداة في سجل
الذكاء بما أنتجته فعلاً.
